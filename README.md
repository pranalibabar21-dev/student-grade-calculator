# student-grade-calculator
Python project to calculate student grades

# Project Overview
This project is a simple Python program that calculates a student's grade based on marks and provides encouraging feedback.

# Objectives
- Take input marks from user
- Validate input (0-100 only)
- Calculate grade using logic
- Display grade with motivational message

# Setup Instructions
1. Install Python (3.x)
2. Clone repository:
   git clone https://github.com/yourusername/your-repo
3. Run program:
   python grade_calculator.py

# Grading Logic
| Marks Range | Grade |
|------------|------|
| 90-100     | A    |
| 75-89      | B    |
| 60-74      | C    |
| 50-59      | D    |
| Below 50   | F    |

# Functions Used
- `calculate_grade(marks)` → returns grade & message
- `get_valid_marks()` → ensures valid input
- `main()` → controls program flow
